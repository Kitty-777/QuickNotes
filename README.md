# 📒 QuickNotes

A beautiful, modern, full-stack note-taking app built with **React**, **TailwindCSS**, and **Firebase**.  
Create, edit, and delete your notes with a sleek and responsive UI — just like flipping through a digital notebook.

## 🚀 Features

- 📝 Create new notes
- 🗂 View and scroll through all notes
- ✏️ Edit notes in real-time
- ❌ Delete notes
- 💫 Beautiful UI with gradients, shadows, and pastel themes
- 🔐 Data saved in real-time using Firebase Firestore

## 🛠 Tech Stack

- **React**
- **TailwindCSS**
- **Firebase (Firestore)**
- **Vite**
